# Local Favorites Tracker

A website for saving favorite local places. The categories include coffee shops, restaurants, dessert spots, and shopping. Add them to your tracker with a rating and note, so you know when you would like to return. 

## Features
You can do the following: 
- Add a place with a name, category, rating, and notes
- Search and filter by category
- Delete a place with a confirmation
- Saves everything so it's still there when you come back
